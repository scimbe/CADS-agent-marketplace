# O3: bp-spatial-audio fertigstellen und messen

Quelltext liegt in blueprints/spatial-audio (noch nie kompiliert). Entwurf: src/lib.rs (Moduldoku).

## Auftrag
- In den Workspace aufnehmen, kompilieren (`RUSTFLAGS=-D warnings`), alle Tests grün; Fehler im Quelltext beheben,
  Entwurf beibehalten (keine Per-Hörer-Mischung, Rendering auf dem Gerät).
- `budget --listeners 50000 --frames 250` auf diesem Host laufen lassen, Bericht (JSON) beilegen; Ziel: p99 < 20 ms,
  Teppich-Zusatzlatenz p99 < 50 ms. Reicht ein Shard mit 50 000 Hörern nicht: die tragende Stellgröße messen
  (Zellgröße, Bed-Komplexität, Bitrate) und die Shard-Größe angeben, die reicht — nicht die Ziele senken.
- blueprint.json für spatial-audio im Schema von blueprints/collab-crdt/blueprint.json, mit den gemessenen Zahlen
  unter `capacity`, und den Grenzen: Medienpfad braucht Datagramme (UDP/QUIC); ct-agents Kanal-Forward ist TCP
  und laut ct-agent docs/channel.md nicht produktiv freigegeben.
