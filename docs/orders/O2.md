# O2: bp-collab-crdt ohne Plattformabhängigkeit nachweisen

Die Blueprint-Beschreibung (blueprints/collab-crdt/blueprint.json, `components[client-core].targets`) verspricht
iOS, Android, Desktop und wasm. `tokio` (net) und `rayon` (sim) bauen nicht für wasm32.

## Auftrag
- Features: `net` (tokio, `src/net.rs`, bin `collab-relay`, Test `tests/net.rs`) und `sim` (rayon, rand, `src/sim.rs`,
  bin `convergence`), beide default. Der Kern (doc, value, stamp, frac, outbox, relay, wire) kommt ohne beide aus.
- `required-features` an Bins und Tests, damit `--no-default-features` sauber baut.
- Nachweis im CI-Workflow (.github/workflows/ci.yml): `cargo check -p bp-collab-crdt --no-default-features --target wasm32-unknown-unknown`
  und `--target aarch64-linux-android` (rustup target add im Job).

## Erlaubte Dateien
blueprints/collab-crdt/Cargo.toml, blueprints/collab-crdt/src/lib.rs, blueprints/collab-crdt/blueprint.json, .github/workflows/ci.yml, Cargo.lock

## Akzeptanz
- Beide `cargo check`-Aufrufe lokal grün (Ausgabe im Bericht), `cargo test -p bp-collab-crdt --release` grün.
- blueprint.json nennt nur Ziele, die nachweislich bauen; was nicht geprüft ist (iOS ohne macOS-Runner), steht dort als ungeprüft.
