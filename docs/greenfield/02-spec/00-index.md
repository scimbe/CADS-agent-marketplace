# Fragment-Spezifikation (aus dem Altcode, Stand app 61cd02e / wrapper 5d8e938)

Altcode = Spezifikation von Verhalten, nicht von Struktur. Jede Datei: Fragment → Quelle (Datei:Zeile) → Tests, die es
festhalten → Invarianten (MUSS im Neuentwurf gelten) → Status (main | PR offen | WIP).
Linkformate werden NEU entworfen (User: geteilte Links müssen nicht kompatibel bleiben); die alten Formate stehen nur als
Referenz für Größen- und Sicherheitsgrenzen in 02-links.md.
